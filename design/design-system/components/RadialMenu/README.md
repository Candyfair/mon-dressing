# RadialMenu

Éventail d’actions de l’appui long sur une pièce (Dressing, Aujourd’hui le soir), façon Pinterest : on glisse vers une icône et on relâche.

- Écran assombri et légèrement flouté ; la pièce se soulève (104 %, ombre portée) ; anneau crème au point d’appui.
- Disques crème `size-radial` (52 pt) répartis sur un arc de rayon `radial-radius` au-dessus du doigt. Il s’ouvre toujours à l’opposé du bord le plus proche et jamais sous le doigt.
- Statut actif : disque teinté de sa couleur. Relâcher sur un statut actif le retire.
- Icône conseillée : 56 pt, anneau et halo `recommend` ; libellé « Conseillé : … » au-dessus de l’éventail tant que rien n’est visé.
- Icône sous le doigt : 62 pt, contour `moss-deep`, son nom au-dessus de l’éventail (pastille `forest-deep`, texte crème ; inversée en sombre).
- Contenu : Dressing = favori, aérer, au sale, ranger, à sécher, sur l’étendoir, à repasser. Aujourd’hui le soir = favori, aérer, au sale, ranger.
- Recommandation : « aérer » tant que la pièce n’a pas atteint le nombre de ports conseillé (repères ADEME), puis « au sale ». L’utilisateur reste libre.
- Les actions sont aussi exposées comme actions d’accessibilité.
