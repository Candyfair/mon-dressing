# OutfitPiece

Une pièce de la tenue, posée sans cadre sur le lin avec son ombre de contact.

- Cadre carré invisible dont la taille suit les règles de la tenue : `garment-top` et `garment-bottom` (même échelle), `garment-shoes`, `garment-layer`, `garment-two-col`.
- Ombre de contact : ellipse de 12 pt de haut sous le bas visible de la pièce, dégradé radial de `contact-shadow` vers transparent, environ 55 % de la largeur du cadre. Les ombres sont dessinées sous toutes les pièces, jamais par-dessus une voisine.
- `space-10` entre deux pièces d’une même colonne, sans chevauchement.
- Toucher : voir la pièce en grand (feuille). Glisser horizontalement : changer de pièce. Appui long : menu flottant.
- Nom accessible = emplacement + nom + état (« Couche 1 : Pull mérinos écru, au balcon, porté 3 fois sur 10 »).
- Le consommateur fournit la photo détourée (ou l’originale en repli). L’illustration de l’aperçu est provisoire.
