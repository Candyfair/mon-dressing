# Button

Boutons texte, en gélule, hors des actions rondes de l’écran Aujourd’hui.

- **Principal** (`md-button-primary`) : `action` / `on-action`, hauteur `size-button`, souvent pleine largeur en bas d’écran (onboarding, « Valider » d’une feuille). Un seul par écran. Vert forêt en clair, moutarde en sombre : y compris à l’onboarding.
- **Contour** (`md-button-outline`) : issue neutre ou sûre (« Garder »), contour `outline-edge`, texte `control-ink`.
- **Suppression** (`md-button-destructive`) : fond `destructive` (prune), texte `cream`. Seulement après une popup de confirmation.
- **Secondaire** (`md-button-secondary`) : action secondaire en prune (« Retirer cette couche »), hauteur `size-tap`.
- **Lien** (`md-link`, déjà défini) : action discrète soulignée (« Passer », « Déjà sec ? », « Revenir aux valeurs de départ »).
- Libellés en verbes d’action, courts ; ils doivent tenir à 200 % de taille de texte (passage sur deux lignes accepté, pas de troncature).
