# EmptyState

État vide d’une catégorie du Dressing, et résultat vide d’un filtre.

- Aucune pièce : silhouette en pointillés (`add-dash`), titre « Aucun haut pour l’instant », texte « Photographiez-les à la suite : quelques secondes par pièce. », AddButton en pilule. Filtres et bouton grille masqués.
- Filtre sans résultat : StatusIcon 64 pt des statuts qui bloquent, avec leur compte (« 5 au sale », « 2 à repasser ») ; titre « Aucun haut disponible » ; phrase qui s’adapte aux statuts présents (« Tous vos hauts sont à laver ou à repasser. ») ; bouton prune « Voir tous les hauts » (retire le filtre) ; lien « Trier le linge → ».
- Ton calme, jamais culpabilisant.
