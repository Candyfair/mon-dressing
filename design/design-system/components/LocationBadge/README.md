# LocationBadge

Badge rond qui dit où se trouve une pièce (balcon, étendoir) sans texte.

- Rond de `size-badge`, fond `location-tint`, icône 15 pt en `bark` (vent pour « au balcon »).
- Posé contre l’épaule droite de la pièce concernée, jamais isolé dans un coin.
- Décoratif pour les lecteurs d’écran : la localisation est annoncée dans le nom accessible de la pièce (« Pull mérinos écru, au balcon »).
