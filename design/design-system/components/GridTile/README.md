# GridTile

Tuile de la grille du Dressing (bouton grille de l’en-tête de filtres), deux pièces par ligne.

- `tile-width` × 190 pt, 12 pt d’écart, coins `radius-tile`, verre (`md-glass`).
- Pièce centrée, 140 pt ; en sombre, `piece-edge`.
- Statuts actifs en StatusIcon 26 pt dans le coin haut droit (favori, balcon, étendoir pour une pièce disponible sur l’étendoir).
- Pas de nom ni de compteur : on reconnaît ses propres vêtements.
- Toucher = fiche ; appui long = RadialMenu. Le bouton de l’en-tête devient « Afficher en carrousel ».
